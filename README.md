# 💎 PetroEconomic AI Pro: Intelligent Investment Appraisal Tool

## 🚀 Overview
**PetroEconomic AI Pro** is a specialized financial decision-support system designed for the oil and gas industry. It bridges the gap between raw production data and executive investment decisions by integrating **Live Market Data**, **Machine Learning Price Forecasting**, and **Advanced Petroleum Economics**.

This tool allows engineers and asset managers to assess the profitability of oil wells in real-time, ensuring that operational decisions are backed by financial viability.

---

## 🛠️ Key Features
- **Live Market Integration:** Automatically fetches real-time Brent Crude prices using Yahoo Finance API.
- **AI-Powered Price Forecasting:** Utilizes a Linear Regression model to analyze 10-year historical trends and predict future price trajectories.
- **Automated Production Analysis:** Processes `CSV` production logs to calculate total revenue, OPEX, and net margins.
- **Advanced Financial Metrics:** Calculates **NPV (Net Present Value)** and identifies the **Payback Period** (Break-even point).
- **Interactive Visualizations:** High-fidelity charts for Cumulative Cash Flow and Market Trend Analysis using Plotly.
